# game_for_birthdays
🕺 Birthday Dance Challenge! 🎈
Welcome to Birthday Dance Challenge, a custom-built rhythm and reflex game created from scratch using Python and Pygame Zero as a special birthday gift! Test your timing, match the arrow keys, and keep the dance party going as long as you can.

✨ Features
Arcade Rhythm Action: Follow the directional prompts (Up, Down, Left, Right) to make the dancer move and rack up points before time runs out.

Festive Visuals: Features a custom procedural particle engine for continuously falling confetti and floating birthday balloons.

Dynamic Audio Tracks: Comes with a dedicated greeting title theme (title.ogg) that seamlessly cuts over to high-energy gameplay music (dance.ogg) the moment the party starts.

Responsive Window Scaling: Designed with flexible scaling to look crisp and vibrant across full screen dimensions.

🚀 How to Play
Launch the game to view the birthday title screen.

Press ENTER to start the music and kick off the countdown!

Use the arrow keys to match the choreography and set a high score.
